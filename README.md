# 二创长编 · 蛎墙 · 应声

这是一部中文二创长篇小说。它借了一款已停服手游给出的人物、称号、阵营名与若干术语，纪元、因果、组织的行为方式全部是本作的发明。全书规划 200 章、十二卷。

## 现在有什么

卷一 两份饭（001 到 017）成稿，卷二 黑色蔷薇（018 到 034）写到 021，共 21 章、66838 汉字。机械核验口径是每章 2800 到 3500 汉字，只数中日韩统一表意文字区间的字，禁用词与跨章重复句一并扫。

## 目录

    README.md                 本文件
    chapters/                 正文章节，文件名是三位全局章号加英文短题
    设定/                      世界观、分卷大纲、状态表、角色卡、流水线
    tools/                    只读的机械核验脚本

设定/状态表.md 是连续性的唯一事实源，每章落地即更新；动笔前先读它的时间锚、已定事实与未解线头。设定/流水线.md 写的是章节怎么生成、怎么审、怎么返工。

## 规矩

- 不解释设定。轮回、深渊、名册等第、安置这些词只当实物和规矩用，设定只通过物、数目、动作露出来。
- 每章章末必须改变状态表里的一项，否则退回重写。
- 第三人称限知，一章一人，不进别人的内心。
- 对白用全角弯引号，行内嵌入的词与唱词用直角引号；歌词在前后章重唱时必须一字不差。
- 不照搬原作台词、剧情正文或道具描述原文；需要引用时压在单句内并标出处。
- 本仓库不含任何解包原文、资源表、密钥或网盘提取码。角色档案表里的官方字段是称号、星等、职业特性、剧情篇名与羁绊名这一类索引信息，不是游戏文本。
- 日子不用现代历法词，按水汛与墙响算：一夜两阵，响满落一道杠。

## 怎么读

从 chapters 里第一张文件往下读即可，不需要预先了解原作。卷一是蛎墙这个镇上的一份饭、一张名册、一道不肯进海的沟；卷二换到蔷薇骑士团那一侧，看的是同一个「按册发放」从另一头长什么样子。

## 站点

仓库根已发布为 GitHub Pages，构建方式是仓库设置里的 legacy 构建，源分支 main、路径根目录。首页是 index.html，套自己写的布局与样式（_layouts/default.html 与 assets/style.css），不是 README 的渲染结果；README 已在 _config.yml 里排除，不出现在站点上。章节目录由 tools/build-index.js 从每章首行的章题生成到 _data/chapters.yml，新增或改章题后重跑一次再提交。正文地址形如 oyster-wall.github.io/chapters/001-shed-skin.html。将来若要把某一本挪到子路径，必须在构建配置里显式设 base 与 root，漏一项就是页面能打开而资源全 404。
